### BagyoWatch PH layers (Philippine disaster feeds)

Four feeds added for BagyoWatch PH. None is stored in this repository — all are
read at runtime through the allowlisted proxy `/api/bagyo/fetch`
(`server/providers/bagyoWatch.js`), which exists because PAGASA, PHIVOLCS and
GDACS send no `Access-Control-Allow-Origin` header, and because a public agency
endpoint should be read through one cached route rather than from every open
tab.

**Freshness.** Every record keeps the provider's own timestamps. PAGASA times
are read as Philippine Standard Time (UTC+8, no DST); GDACS times without a
zone are read as UTC. An alert past its own `valid` time is drawn faded and
counted as *expired*, never as active, so "no active warnings" stays true. A
feed that answers with an unexpected shape raises a `MalformedFeedError` and
shows as an error instead of drawing something it cannot verify.
